# ADR placard assets

The SVG files in this directory are displayed as local, resolution-independent
ADR/UN transport hazard placards.

- Most class assets are distributed by `@ghs-hazard-pictograms/assets` 1.1.0
  under the MIT License. Project: https://github.com/karlnorling/ghs-hazard-pictograms
- `class-9a.svg` is the UNECE ADR 9A artwork obtained from Wikimedia Commons
  and marked there as public domain.
- `class-7d.svg` is the UNECE ADR 7D artwork distributed by Openclipart and
  marked there as public domain.

The asset files are kept local so the application does not depend on an
external image service at runtime.
